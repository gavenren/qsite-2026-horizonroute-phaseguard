# Shallow VQE preparation map

The completed map has 225 points on a 15 by 15 grid. It uses eight spins and periodic ANNNI interactions. Each preparation circuit has four layers, 32 RY gates, and 28 CNOTs on a nearest-neighbor chain.

The clean objective is energy plus `0.5*(1 - <X0 X1 ... X7>)`. Global spin flip is a symmetry of this Hamiltonian. For positive field, its ground state is even under this symmetry. No phase labels or target-state fidelity enter the training objective.

The sweep uses earlier solutions and three independently optimized control states as starting points. Each optimizer trial permits at most 200 iterations. There are at most two rescue trials if the objective error exceeds 0.0025 per site. A final pass uses neighboring solutions at 95 points with large errors. That pass also permits at most 200 iterations per point. All trial stop states are saved. The selected optimizer reports convergence at 196 of 225 points. The other points are bounded optimization results.

For each point, the same clean parameters are used at p=0, 0.01, and 0.05. A target depolarizing channel follows every CNOT. The noise data therefore come from actual preparation circuits. They are not generated by an end-of-circuit noise channel or by noise on an ideal state input.

The fast density engine is checked against PennyLane. Twelve checks of saved map points agree within 1.13e-12 for correlations, 1.46e-11 for energy, and 5.15e-13 for fidelity.

## Results and limits

- Clean labels agree with the exact reference at 221 of 225 points (98.22%). The fixed threshold is 0.5628839496768857.
- Mean clean fidelity at positive field is 0.98519. The minimum is 0.66459.
- Twelve positive-field points have fidelity below 0.95. Mark these points as preparation-uncertain. They occur near the frustrated region.
- Mean clean energy error is 0.00401 per site. The maximum is 0.01896 per site.
- The clean map has 34 ferro-like, 36 antiphase-like, and 155 weak-order points.
- At p=0.01, the counts are 33, 34, and 158. At p=0.05, all 225 points are below the order threshold.

These are finite-system detection maps. Noise affects the prepared state and the detected order. It does not change the Hamiltonian's equilibrium phase boundaries. The three classes do not establish a floating phase.

At h=0, the exact ground state can be degenerate. The file saves both overlap with the chosen symmetric ground state and total weight in the ground space. Use ground-space fidelity to judge this row. The h=0.0, kappa=0.5 point needs a separate ambiguity marker.

## Files

- `variational_grid_N8.npz`: final maps, parameters, exact comparisons, and stop flags.
- `initial_grid_N8.npz`: map before the final neighbor pass.
- `metadata.json`: scan settings and each initial trial.
- `refinement.json`: final neighbor-pass records.
- `summary.json`: final numerical summary.
- `audit.json`: PennyLane checks, clean confusion matrix, and low-fidelity points.
- `run_map.py`, `refine_map.py`, `audit_map.py`: reproduction scripts.

## Reproduction

Run the scripts in this order with one thread for each numerical library:

```bash
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 python variational_map/run_map.py
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 python variational_map/refine_map.py
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 python variational_map/audit_map.py
```

The scan took 551 seconds. The neighbor pass took about 21 seconds. The scripts use PennyLane 0.44.1. The package uses local relative paths. Run from the scientific package directory.
